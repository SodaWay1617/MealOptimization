# MealOptimization

Локальная книга рецептов и планировщик питания поверх Markdown. Приложение открывает заметки Obsidian, собирает меню, считает продукты и создаёт ссылки на корзины Ленты и ВкусВилла.

## Запуск

Из корня репозитория запустите Docker Compose.

```powershell
docker compose up --build -d
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). При запуске без локальных настроек подключается [демонстрационная база](Пример%20базы/README.md) с тремя рецептами и сохранённым планом. Для каталога и случайного подбора API-ключ не нужен.

## Своя база Obsidian

Один раз скопируйте шаблон `.env.example` в корневой `.env`, если файла ещё нет.

```powershell
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
```

В корневом `.env` укажите свои папки. Используйте пути относительно корня репозитория или абсолютные пути с прямыми слэшами.

```dotenv
MEAL_RECIPES_DIR='D:/Obsidian/Питание/Рецепты'
MEAL_PLANS_DIR='D:/Obsidian/Питание/Планы питания'
MEAL_PORT=8080
```

Папка «Планы питания» должна находиться рядом с «Рецепты», чтобы относительные ссылки из новых планов открывались в Obsidian. Контейнер читает и записывает файлы в обе папки. Изменения, сделанные в Obsidian, можно подхватить кнопкой «Обновить» в каталоге. Значения из окружения текущего окна PowerShell имеют приоритет над `.env`.

```powershell
docker compose config --quiet
docker compose up -d
docker compose ps
```

После изменений кода используйте `docker compose up --build -d`. Остановка — `docker compose down`. Журналы контейнера доступны через `docker compose logs meal-planner`.

## AI и магазины

Для AI-функций скопируйте `meal-planner/config/.env.example` в `meal-planner/config/.env`, если файла ещё нет. Для OpenRouter укажите `LLM_PROVIDER=openai_compatible`, `LLM_API_BASE=https://openrouter.ai/api/v1`, идентификатор модели и свой `LLM_API_KEY`. При необходимости закрепите маршрут, например `LLM_OPENROUTER_PROVIDER=deepinfra`. Затем выполните `docker compose up -d`.

- В каталоге можно добавить рецепт вручную или через AI. AI готовит черновик на одну порцию. Подтверждение сохраняет ингредиенты, шаги, примерное КБЖУ и теги в Markdown. При добавлении рецепт появляется в соответствующей индексной таблице Obsidian.
- В «Плане питания» доступны архив и создание меню на выбранные даты. Для подбора используются AI-синхронизированные рецепты. Количество продуктов рассчитывается по числу дней и едоков для каждого блюда, а итоговый план сохраняется в Markdown.
- Для Ленты можно сохранить ориентировочную цену порции, дату расчёта и пропуски. Подбор товаров для корзины доступен в Ленте и ВкусВилле через их MCP. Корзина открывается по ссылке, а наличие по адресу, итоговую сумму и оплату подтверждает магазин.
- Во вкладке «Предпочтения» можно сохранить правила для AI и до трёх ссылок на товары каждого магазина. Правила, ссылки и последний выбранный магазин хранятся в браузере.

При использовании AI текст выбранной заметки или запрос и данные для подбора отправляются настроенному LLM-провайдеру. При поиске магазинов Ленты введённый адрес отправляется Ленте. Храните ключи в локальном файле конфигурации.

## Разработка

| Путь | Назначение |
| --- | --- |
| `web/` | React-интерфейс |
| `meal-planner/app/web/` | Flask API и интеграции веб-приложения |
| `meal-planner/app/` | Сканирование, SQLite, синхронизация, планирование, покупки и цены |
| `meal-planner/tests/` | Автоматические тесты |
| `Пример базы/` | Демонстрационные Markdown-файлы |

Для CLI и тестов нужен Python 3.11+. Команды ниже запускаются из корня.

```powershell
Push-Location meal-planner
python cli.py --help
python cli.py scan --root '../Пример базы/Рецепты' --with-hash --output tsv
python -m unittest discover -s tests
Pop-Location
```

CLI использует свои локальные индексы SQLite. Без `--root` он читает `Питание/Рецепты`, если папка существует, иначе использует демонстрационные рецепты. Команда `scan --update-index` обновляет индекс, `sync --dry-run --all` показывает очередь без отправки запросов, а `plan --seed 42` строит план из синхронизированных данных CLI. Сгенерированные CLI-планы по умолчанию сохраняются в локальной папке `Питание/Планирование`. Все параметры доступны через `python cli.py <команда> --help`.

Для ручной проверки откройте демонстрационный план, перейдите из него к рецепту и соберите новое меню на два дня. Суп на двоих за два дня должен дать четыре порции и 240 г чечевицы в покупках. Изменения с записью заметок проверяйте в отдельной копии базы.

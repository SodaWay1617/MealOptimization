# Пример базы рецептов

Откройте папку `Пример базы` как отдельное хранилище Obsidian. В ней три демонстрационных рецепта, таблицы со ссылками и план на два дня. КБЖУ приведены как пример структуры.

```text
Пример базы/
├── Рецепты/
│   ├── Рецепты.md
│   ├── Завтраки/
│   │   ├── Завтраки.md
│   │   ├── Категории/
│   │   └── Заметки/
│   └── Супы/
│       ├── Супы.md
│       └── Заметки/
└── Планы питания/
    └── План питания 2026-11-23 — 2026-11-24.md
```

Чтобы открыть пример в приложении, запустите отдельный экземпляр Docker Compose из корня проекта. Он будет доступен на [порту 8081](http://127.0.0.1:8081).

```powershell
$env:MEAL_RECIPES_DIR = './Пример базы/Рецепты'
$env:MEAL_PLANS_DIR = './Пример базы/Планы питания'
$env:MEAL_PORT = '8081'
docker compose -p meal-example up --build -d
```

Чтобы остановить пример, выполните `docker compose -p meal-example down`. Для возврата к своим настройкам откройте новое окно PowerShell.
